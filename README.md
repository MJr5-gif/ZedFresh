# ZedFresh Groceries 

A landing page for a fictional grocery delivery startup based in Lusaka, Zambia. Built as part of my Week 1 HTML practice.

## About
ZedFresh delivers fresh produce, meat, and everyday groceries to homes and offices across Lusaka within 2 hours, sourced directly from local Zambian farmers.

## Features
- Hero section with call-to-action buttons
- Product showcase with pricing
- Delivery fee table
- Customer reviews
- Contact form

## Built With
- HTML5 (semantic markup)

## What I Practiced
- Semantic tags: `<header>`, `<nav>`, `<section>`, `<article>`, `<figure>`, `<address>`
- HTML tables with `<thead>`/`<tbody>`
- Forms with proper labels
- The `<data>` tag for machine-readable pricing
